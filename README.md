# napcat-plugin-index

我写的 NapCat 插件列表页，方便统一查版本和跳转安装。

## 插件清单

| 插件 | 描述 |
|------|------|
| [napcat-plugin-fun-pack](https://github.com/sanxi33/napcat-plugin-fun-pack) | 群聊娱乐功能合集：二选一、今天吃什么、龙图、d20 等等 |
| [napcat-plugin-ai-chat-template](https://github.com/sanxi33/napcat-plugin-ai-chat-template) | AI 聊天模板插件，支持外置 Prompt、WebUI 管理 |
| [napcat-plugin-index](https://github.com/sanxi33/napcat-plugin-index) | 就是这个页面，所有插件的导航索引 |

有新的插件会往这里加。
